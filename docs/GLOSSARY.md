# Glosario técnico

- **Offline-first:** diseño que privilegia estado y operaciones locales; servicios remotos optativos.
- **Workspace:** interfaz y conjunto de herramientas para un dominio, no un documento independiente.
- **Estado canónico / fuente de verdad:** única representación editable y autoritativa del proyecto.
- **Scene graph:** jerarquía de nodos y relaciones espaciales con transformaciones.
- **UUID / ID estable:** identificador que permite referir al mismo objeto después de guardar/reabrir.
- **Sketch:** geometría 2D editable, posiblemente restringida paramétricamente.
- **B-Rep:** representación de sólido por fronteras, superficies y topología.
- **Mesh / malla:** triángulos/polígonos adecuados para visualización, no necesariamente CAD paramétrico.
- **PBR:** shading basado en propiedades físicas; metalness, roughness, normal y texturas.
- **HDRI:** imagen de alto rango dinámico usada como entorno/iluminación.
- **Viewport:** vista interactiva para navegar y editar.
- **Render final:** cálculo de salida con mayores opciones de calidad y/o tiempo.
- **glTF / GLB:** formatos de intercambio de escena/mesh/materiales, no proyecto CAD editable completo.
- **DXF:** intercambio de dibujos CAD; cobertura depende del importador.
- **IFC:** estándar abierto de información BIM.
- **BIM:** modelo con información semántica de construcción, no solo geometría 3D.
- **WASM / WebAssembly:** formato ejecutable sandbox utilizado en navegadores y otros entornos.
- **Tauri:** framework para empaquetar aplicaciones de escritorio que usan interfaz web.
- **AGPL-3.0-only:** licencia GNU Affero General Public License 3 sin cláusula «o posterior».
- **ADR:** registro de decisión de arquitectura con contexto, decisión y consecuencias.
- **PoC / spike:** experimento técnico aislado para validar una hipótesis antes de diseñar una solución definitiva.
- **Round-trip:** guardar→abrir o exportar→importar y comprobar fidelidad de datos.
- **NFR:** requisito no funcional, como seguridad o disponibilidad offline.
- **Fixture:** archivo/escena conocida usada para tests de regresión.
- **Clean-room:** técnica de desarrollo independiente para implementar comportamiento descrito sin copiar código protegido.
