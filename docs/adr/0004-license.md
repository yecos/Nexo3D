# ADR-0004: Licencia libre AGPL-3.0-only

**Estado:** Aceptada · 2026-10-13

**Contexto:** el objetivo es permitir a todas las personas usar, modificar y redistribuir el programa; conservar libertad de mejoras redistribuidas y servicios modificados dentro de lo previsto por AGPL.

**Decisión:** licenciar el código original de NEXO 3D como **GNU Affero General Public License v3.0 only**, identificador SPDX `AGPL-3.0-only`; incorporar texto íntegro en `LICENSE`.

**Consecuencias:** uso personal y comercial permitido conforme a licencia, obligaciones de copyleft y, para versiones modificadas usadas por usuarios mediante red, cumplimiento de las disposiciones aplicables de oferta del código fuente. Activos de terceros, bibliotecas y contenido generado pueden tener licencias distintas; deben inventariarse. **No se transfiere automáticamente la titularidad** de contribuciones.

**Alternativas consideradas:** MIT/Apache (permisivas, sin protección copyleft equivalente); GPL-3.0 (sin la misma disposición de interacción remota que AGPL).

**Validación:** LICENSE, README, avisos y auditoría de componentes importados. Ninguna extensión o excepción de licencia se presupone aplicable a código ajeno.

> Este ADR define política técnica; no reemplaza asesoría legal sobre casos de licencias compuestas.
